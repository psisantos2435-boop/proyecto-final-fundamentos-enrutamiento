ROL EN LA TOPOLOGÍA
--------------------------------------------------------
SMC1 es el switch de capa 3 (multicapa) que actúa como el
punto central de enrutamiento entre VLANs para las redes
de Servidores, Empleados, Finanzas, TI y WIFI. Se conecta
hacia arriba (Gi1/1/1) con R3-DHCP para salir al resto de
la topología, y hacia abajo con SW3 mediante un
EtherChannel (Port-channel2).

PROCESO DE CONFIGURACIÓN (explicado paso a paso)
--------------------------------------------------------
1. Identificación del equipo:
   Se asigna el hostname "SMC1" y un banner MOTD de aviso
   legal para dejar constancia de que el acceso es
   restringido y quién es el responsable del equipo.

2. Seguridad de acceso administrativo:
   - "enable secret" cifra la contraseña de modo
     privilegiado.
   - "service password-encryption" cifra el resto de
     contraseñas en texto plano de la configuración.
   - Se crean usuarios locales (Admin y matrícula) con
     privilegio 15 para poder administrar el equipo por
     SSH.
   - Se genera el dominio (ip domain-name) y el par de
     llaves RSA, requisitos para habilitar SSH versión 2.
   - En las líneas VTY se exige login local y se restringe
     el acceso remoto únicamente a SSH (no Telnet).

3. Habilitación de enrutamiento entre VLANs:
   "ip routing" activa la función de capa 3 del switch,
   necesaria para que las interfaces VLAN (SVIs) puedan
   enrutar tráfico entre sí.

4. Creación de VLANs:
   Se crean las VLAN 2 (Servidores), 3 (Empleados),
   4 (Finanzas), 5 (TI), 6 (WIFI) y 7 (Nativa), cada una
   con su nombre descriptivo para facilitar la
   administración.

5. Interfaces VLAN (SVI) como gateway de cada red:
   Cada "interface vlan X" recibe la IP que funcionará
   como gateway de esa subred, y un "ip helper-address"
   que reenvía las solicitudes DHCP broadcast hacia el
   servidor R3-DHCP (unicast), ya que el servidor DHCP no
   está en la misma red.

6. Enlace hacia el router DHCP/rutas (Gi1/1/1):
   Se configura como interfaz enrutada ("no switchport")
   con IP punto a punto hacia R3-DHCP, permitiendo que
   SMC1 tenga salida hacia el resto de la red.

7. EtherChannel hacia SW3:
   Los puertos Gi1/0/22-23 se agrupan en el
   Port-channel2 con LACP en modo "active". El
   Port-channel se configura como troncal (trunk),
   permitiendo el paso de las VLANs 2-7, con VLAN nativa
   7 y "switchport nonegotiate" para no negociar DTP
   (mitiga ataques de VLAN hopping).

8. Enlace trunk adicional (Gi1/0/24):
   Se deja un enlace trunk independiente permitiendo solo
   las VLANs 6 y 7 (probablemente hacia SW4, rama WIFI).

9. Seguridad de capa 2 (corrección [2]):
   - "ip dhcp snooping" habilitado sobre las VLANs de
     datos, evita que un DHCP falso (rogue) entregue IPs
     en la red; solo el puerto/uplink de confianza hacia
     R3-DHCP puede responder ofertas DHCP.
   - "ip arp inspection" (DAI) valida que las direcciones
     MAC e IP de los paquetes ARP coincidan con la base de
     snooping, evitando ataques de ARP spoofing/envenena-
     miento.

10. Ruta por defecto:
    Se apunta la ruta 0.0.0.0/0 hacia R3-DHCP para que
    todo el tráfico sin ruta específica salga por ese
    camino.

11. Guardado de la configuración:
    "end" + "wr" (write) guarda la configuración en la
    NVRAM para que persista tras un reinicio.
