ROL EN LA TOPOLOGÍA
--------------------------------------------------------
SW1 es un switch de acceso para las VLANs 300
(Docentes/Estudiantes) y 500 (Académicos). Forma, junto
con SW2, un EtherChannel LACP (Port-channel1) que conecta
ambos switches entre sí y hacia arriba con los routers R1
y R2, quienes proveen enrutamiento y redundancia HSRP para
estas VLANs. SW2 es el puente raíz de STP para este
segmento; SW1 queda como puente raíz secundario.

PROCESO DE CONFIGURACIÓN (explicado paso a paso)
--------------------------------------------------------
1. Identificación: hostname "SW1" y banner MOTD.

2. Creación de VLANs 300 (Docentes/Estudiantes), 500
   (Académicos) y 999 (Admin/Nativa, usada como VLAN
   nativa de los enlaces troncales para separar el tráfico
   de administración).

3. Puertos de acceso:
   - fa0/6 y fa0/20 -> VLAN 300
   - fa0/9 y fa0/17  -> VLAN 500
   Cada uno con portfast, bpduguard y port-security
   (máximo 2 MAC, violación shutdown, sticky), mismo
   criterio de seguridad aplicado en toda la topología.

4. EtherChannel hacia SW2 (fa0/23-24, channel-group 1
   modo active/LACP), formando el Port-channel1, que se
   configura como trunk permitiendo las VLANs 300, 500 y
   999, con VLAN nativa 999 y "switchport nonegotiate".

5. Enlace trunk adicional gig0/1:
   Con la misma configuración de VLANs permitidas y VLAN
   nativa, probablemente el uplink hacia los routers R1/R2
   (router-on-a-stick).

6. Spanning-tree:
   "spanning-tree vlan 300,500,999 root secondary" designa
   a SW1 como puente raíz de respaldo, de modo que si SW2
   (raíz primario) falla, SW1 tome el rol sin reconfigurar
   manualmente la prioridad.

7. Seguridad de capa 2 (DHCP Snooping + DAI) sobre las
   VLANs 300 y 500, confiando en el Port-channel1 y en
   gig0/1 como enlaces por donde puede llegar tráfico DHCP
   legítimo desde R3-DHCP.

8. Guardado: "end" + "wr".

COMANDOS APLICADOS (configuración completa)
--------------------------------------------------------
enable
configure terminal

hostname SW1

banner motd #
ACCESO SOLO AUTORIZADO
Frederick Alexander Santos Rivera
2025-0822
#

vlan 300
 name DOCENTES_ESTUDIANTES
vlan 500
 name ACADEMICOS
vlan 999
 name ADMIN_NATIVA

interface fa0/6
 switchport mode access
 switchport access vlan 300
 spanning-tree portfast
 spanning-tree bpduguard enable
 switchport port-security
 switchport port-security maximum 2
 switchport port-security violation shutdown
 switchport port-security mac-address sticky
 no shutdown
 exit

interface fa0/20
 switchport mode access
 switchport access vlan 300
 spanning-tree portfast
 spanning-tree bpduguard enable
 switchport port-security
 switchport port-security maximum 2
 switchport port-security violation shutdown
 switchport port-security mac-address sticky
 no shutdown
 exit

interface fa0/9
 switchport mode access
 switchport access vlan 500
 spanning-tree portfast
 spanning-tree bpduguard enable
 switchport port-security
 switchport port-security maximum 2
 switchport port-security violation shutdown
 switchport port-security mac-address sticky
 no shutdown
 exit

interface fa0/17
 switchport mode access
 switchport access vlan 500
 spanning-tree portfast
 spanning-tree bpduguard enable
 switchport port-security
 switchport port-security maximum 2
 switchport port-security violation shutdown
 switchport port-security mac-address sticky
 no shutdown
 exit

interface range fa0/23-24
 channel-group 1 mode active
 exit

interface port-channel 1
 switchport mode trunk
 switchport trunk native vlan 999
 switchport trunk allowed vlan 300,500,999
 switchport nonegotiate
 no shutdown
 exit

interface gig0/1
 switchport mode trunk
 switchport trunk native vlan 999
 switchport trunk allowed vlan 300,500,999
 switchport nonegotiate
 no shutdown
 exit

spanning-tree vlan 300,500,999 root secondary

! --- Seguridad adicional ---
ip dhcp snooping
ip dhcp snooping vlan 300,500
no ip dhcp snooping information option
interface port-channel 1
 ip dhcp snooping trust
 exit
interface gig0/1
 ip dhcp snooping trust
 exit

ip arp inspection vlan 300,500
ip arp inspection validate src-mac dst-mac ip
interface port-channel 1
 ip arp inspection trust
 exit
interface gig0/1
 ip arp inspection trust
 exit

end
wr
